Tekan butang pintasan di bawah satu demi satu, kemudian tampal URL yang anda dapat di sini:

Pembantu Pintasan Google Sheet (Tekan Ikut Nombor):

  1. Apabila Google Sheet terbuka, tekan menu atas Extensions ➔ Apps Script.
  2. Padam kod asal di dalamnya, tekan Paste (Ctrl+V) kerana kod sudah disalin tadi, dan tekan ikon Save (💾).
  3. Tekan butang biru Deploy (kanan atas) ➔ New deployment ➔ pilih jenis Web app.
  4. Tukar Who has access kepada Anyone ➔ tekan Deploy, dan salin Web app URL ke dalam kotak di atas!

Pembantu Pintasan GitHub (Tekan 2 Butang Ini Sahaja):

Butang B 2. Buka Halaman Repo GitHub ↗

Selepas Tekan Butang B di Atas:

  1. Pada kotak Repository name, taip kemaswang dan tekan butang hijau Create repository di bawah.
  2. Tekan tulisan biru "uploading an existing file".
  3. Tarik masuk fail index.html (daripada Butang A tadi), kemudian tekan butang hijau Commit changes.
  4. Tekan tab Settings (di atas) ➔ menu Pages (di kiri) ➔ tukar Branch daripada None kepada main dan tekan Save.
